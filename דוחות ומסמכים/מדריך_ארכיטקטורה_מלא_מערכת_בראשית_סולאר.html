1. מודל הפריסה (Deployment)

כל המערכת (חוץ משני הכלים העצמאיים) רצה כ-Google Apps Script Web App אחד: פרויקט Apps Script יחיד שמכיל את code.js (בקוד Apps Script זה בפועל קובץ Code.gs) וארבעה קבצי HTML (Index, Form, Calculator, PrintQuote), ומחובר לגיליון Google Sheets אחד עם שלוש לשוניות. הניתוב כולו קורה בפונקציה אחת — doGet(e) — לפי פרמטר ה-URL page:

URLקובץ שמוגששיטת הגשה

?page=print&clientId=XPrintQuote.htmlcreateTemplateFromFile (ללא הזרקה בפועל — clientId נקרא מה-URL בצד לקוח, זהה לדפוס של Calculator)

5. Form.html — טופס הלקוח

5.3 ההצפנה — RSA-OAEP + AES-256-GCM היברידי

שלבפרט

אין שום מפתח פרטי בקובץ זה — פענוח אפשרי רק דרך כלי הפענוח העצמאי (סעיף 8.2).

8. שני הכלים העצמאיים

8.1 עורך תבנית (עריכת_תבנית...html)

לא חלק מ-doGet. "דלת מנהל" (window.ADMIN_MODE) שנפתחת בתוך עותק מוטמע (base64) של PrintQuote.html בתוך iframe#quote-frame, עם פאנל ניהול לגרירת עמודים, עריכת תמונות ברירת מחדל, וייצוא תבנית מעודכנת. מיועד לעדכון בסיס העיצוב בלבד, לא לשימוש יומיומי.

8.2 כלי פענוח נבנה בסבב זה

קובץ HTML עצמאי לחלוטין (לא חלק מ-Web App, לא CDN, לא Google Apps Script) — נפתח ישירות מהמחשב. מטרתו: לפענח קבצי .json.enc שמגיעים מ-Form.html, באמצעות מפתח פרטי RSA שקיים רק בזיכרון הדפדפן ברגע השימוש. פלט: JSON גלוי בפורמט bereshit-solar-consumption-data-v1 — מוכן להעלאה ישירה ל-Calculator.html דרך handleImportedEstimateFile.

9. מפות זרימה מקצה-לקצה

9.1 יצירת הצעת מחיר חדשה (מקצה לקצה)

  1. איש מכירות פותח את Index.html, ממלא פרטי לקוח ומקורות/צרכנים, לוחץ שמור → saveDataToSheet() → google.script.run.saveCustomerData → שורה חדשה/מעודכנת בגיליון.
  2. בונה כרטיסיית רכיבי מערכת (פאנלים/מצברים/ממירים) — ידנית או דרך הצע שילובים (runSuggestionEngine).
  3. לוחץ פתח מחשבון → openCalculatorWindow() → חלון חדש עם ?page=calculator&clientId=X&roofArea=Y.
  4. במחשבון: מזין/מייבא נתוני צריכה, מריץ סימולציית דיספאץ' ומודל פיננסי, לוחץ העבר תוצאות → transferDataToQuote() → localStorage + updateCalculatorResults לשרת.
  5. חוזר ל-Index.html, לוחץ משוך נתונים מהמחשבון → pullDataFromCalculator() (localStorage, ובגיבוי — שרת) → applyCalculatorData().
  6. לוחץ הדפס הצעה → openPrintWindow() → localStorage['pendingQuote'] + updateCalculatorResults לשרת + חלון חדש עם ?page=print&clientId=X.
  7. PrintQuote.html טוען (localStorage, ובגיבוי — שרת דרך mapServerCustomerToQuoteData), מזין הנחות-יסוד למנוע הפנימי, ומציג הצעה מוכנה להדפסה/PDF.

9.2 טופס לקוח ← פענוח ← מחשבון

  1. הלקוח פותח ?page=form&clientId=X (קישור שאיש המכירות מעתיק מ-Index.html דרך copyFormLink) — הטופס מנסה למלא-מראש שם/טלפון/כתובת דרך fetchCustomerData.
  2. הלקוח ממלא מיקומים/קטגוריות/מכשירים, הטופס שומר אוטומטית מקומית (scheduleAutosave).
  3. בסיום, buildExportPayload() מכינה JSON גלוי, ואז הצפנה (RSA+AES) ← הורדת קובץ ...json.enc.
  4. הלקוח שולח את הקובץ לבראשית סולאר (מייל/וואטסאפ וכו' — מחוץ למערכת).
  5. איש הצוות פותח את כלי הפענוח (מקומית), טוען מפתח פרטי, מעלה את הקובץ, מפענח, ומוריד JSON גלוי.
  6. ב-Calculator.html, מעלה את ה-JSON הגלוי דרך שדה "קובץ צריכה" → handleImportedEstimateFile קולטת את hourlySeries ישירות (ללא צורך לשחזר את מנוע ההיררכיה).
